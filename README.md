# リコリコ 設定判別アプリ

アップロードされた `リコリコ判別.xlsx` の確率表を読み取り、設定1〜6の相対的な推測割合を表示する、静的Webアプリです。スマートフォン・PC対応。**依存ライブラリ・ビルド・サーバーは不要**で、GitHub Pagesにそのまま公開できます。

## GitHub Pages で公開する手順

1. GitHubで新しい **Public** リポジトリを作成します（例：`ricorico-setting`）。
2. このフォルダの**中身** `index.html`, `app.js`, `calculator.js`, `data.js`, `style.css`, `.nojekyll`, `README.md` をリポジトリのルートにアップロードします（`tests/` も任意でアップロード可能）。
3. リポジトリの **Settings → Pages → Build and deployment → Deploy from a branch** を選び、`main` ブランチの `/(root)` を指定して **Save** します。
4. デプロイ後、通常は `https://＜ユーザー名＞.github.io/＜リポジトリ名＞/` でアクセスできます。正確な公開URLは Pages 設定画面に表示されます。

`index.html` をPCで直接開いても動作します。インターネット接続は不要です。

## アプリの使い方

- **CZ当選（駆け抜け・通常・上位）**：各ゾーンの試行回数と当選回数。
- **共通ベル**：総ゲーム数と共通ベル成立回数。
- **当選時の内訳**：OPP、幼少期、直撃の観測回数。すべての種類をできるだけ漏れなく数えます。
- **AT終了画面**：見た終了画面の回数を種類別に記録。
- **エピソード**：EP1〜4の発生回数を記録。
- 入力はブラウザの `localStorage` に自動保存されます。**入力を保存**（JSON）でバックアップし、別端末で**読み込む**ことができます。
- **設定別確率の確認・編集**では、元Excelから抽出した確率の確認・変更ができます（変更はローカル端末にのみ反映）。

## 元Excelに存在する注意点

- `設定1!C108`（**当選時直撃・設定5**）は元Excelで **0.22（22%）** です。一方で当選時カテゴリーの設定5の合計は **119.8%** になっています。
- 同じく当選時の合計が設定1と設定4では100.1%です（丸めのため許容差0.25ポイント）。
- 元Excelの一部の集計式に **`#REF!`** があります。アプリの計算ではこれらの式を使わず、設定別確率だけを読み取っています。
- **データの改変を避けるため**22%は自動では修正せず、当選時グループは合計が不正な間、全設定とも推測に使いません。アプリの警告の「22%を2.2%へ変更する」ボタンは**ユーザーが押した場合のみ**変更され、元の `data.js` は不変です。その数字が正しいかは必ず原典で確認してください。
- 0%・100%は入力結果と矛盾した場合、設定の確率を正確に0にします。全設定で矛盾すると「推測不能」と表示します。

## 推測ロジック

初期の事前確率は設定1〜6で均等（各1/6）。CZ各ゾーンおよび共通ベルについては各設定の `Binomial(n, p)` の尤度を、当選時・終了画面・エピソードについてはすべてのカテゴリーを記録したと仮定した多項分布の尤度を使います。設定に依存しない組合せ係数は正規化時に相殺するため省略し、下記の対数尤度で数値的に安定に計算します。

```
log L_s = Σ binomial ( k log(p_s) + (n-k) log(1-p_s) )
          + Σ categorical ( count_i log(p_{s,i}) )
posterior_s = exp(log L_s - max(log L)) / Σ exp(log L_j - max(log L))
```

**仮定・限界**：各観測は条件付きで独立、確率表は正しい、同じ設定で遊技を継続した、とみなします。結果はモデル上の比較値であり、実際にその設定である確率を保証しません。CZの試行母数はゾーンに到達した機会を正しく数えてください。カテゴリーグループでは一部結果だけではなく、発生したすべてのカテゴリーを記録してください。割合の和が100%から0.25パーセントポイント超ずれているカテゴリーグループは計算から除外します。

## 開発・テスト

Node.jsがあれば標準ライブラリだけで計算テストを実行できます。

```bash
node --test tests/calculator.test.cjs
```

ファイル構成：`index.html`（画面）、`style.css`（レスポンシブUI）、`app.js`（操作と保存）、`calculator.js`（推定計算）、`data.js`（Excel数値、設定ごとに元セル番地付き）、`tests/`（計算テスト）。

このツールは非公式で、作品の権利者や遊技機メーカーとは関係ありません。
